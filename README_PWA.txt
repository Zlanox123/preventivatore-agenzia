PREVENTIVATORE AGENZIA - PWA

Carica nella root del repository GitHub:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-180.png
- icon-192.png
- icon-512.png

Poi attiva GitHub Pages sulla branch main, cartella /(root).

Su iPhone:
Safari -> apri il sito -> Condividi -> Aggiungi alla schermata Home.

Dopo il primo caricamento completo, la PWA può funzionare offline.
